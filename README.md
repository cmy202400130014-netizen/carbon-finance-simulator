# 电碳金融仿真系统

项目评审使用的交互式仿真程序。输入情景参数后，可比较火电企业的碳履约支出、估算欧式碳期权价值、核对发电与碳排放数据，并查看绿色金融指标的年度评价。程序支持 CSV 批量测算、结果导出和内置检测。

## 打开评审版

1. 在仓库的 **Code** 菜单选择 **Download ZIP**。
2. 解压后，双击 `index.html`，用浏览器打开程序。首次打开即可看到政策收紧情景的履约测算结果。
3. 调整到期现货碳价、配额缺口等参数，核对单组结果。需要同时比较多组输入时，进入「分组情景测算」，下载模板并按样例填写后导入。
4. 在「自动检测」页选择「全部模块」运行内置检查。需要留存的测算结果可导出为 CSV。

程序在浏览器本地计算，可离线运行。内置工况和指标矩阵用于演示。正式复算时，请按相同单位和统计口径填写自己的数据。
